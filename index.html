수업 데이터 · TV 설정

구글 시트 한 행이 카드 한 장이 됩니다. 연결하지 않아도 기본 수업을 사용할 수 있어요.

01 · Google Sheets CSV 연결

구글 시트에서 파일 → 공유 → 웹에 게시 → 수업 탭 → 쉼표로 구분된 값(.csv)을 선택해 게시한 주소를 넣으세요. 열 위치는 바뀌어도 되지만 첫 행의 영문 열 이름은 유지해 주세요.

공개용 수업 내용만 넣으세요. 학생 이름, 성적, 연락처나 비공개 자료를 게시하지 마세요.

PC에서 시트를 연결한 뒤 TV용 index.html 저장을 누르면 연결 주소와 현재 수업을 파일 안에 넣습니다. 그 파일을 웹사이트에 올리면 TV에서 긴 CSV 주소를 다시 입력할 필요가 없습니다.

02 · 화면과 읽기 방식

전체 화면, 리모컨 키 전달, 한국어 음성은 TV 모델과 브라우저 지원에 따라 달라집니다. 브라우저 주소창을 웹페이지에서 강제로 없앨 수는 없습니다. 화면 높이는 실제 사용 가능한 영역에 맞춰집니다.

03 · 오디오

음성 지원 확인 중…

CSV의 audio_url에 공개 MP3 주소를 넣으면 그 파일을 먼저 재생합니다. 비어 있으면 기기의 한국어 음성을 사용합니다. 한국어 음성이 없는 TV에서는 녹음 파일이나 교사의 읽어 주기를 이용해 주세요. 합성 음성은 발음 채점 기능이 아닙니다.

04 · 데이터 관리

위치와 다시 읽기 표시는 이 브라우저에만 저장됩니다. 다른 기기나 Google Sheets로 학생 기록을 전송하지 않습니다. 원격 CSV나 음성 파일을 불러올 때는 해당 제공자와 통신합니다.

수업 도구

같은 카드를 다른 순서와 속도로 연습하세요.

자동 진행은 소리를 자동 재생하지 않습니다. 화면을 넘기거나 메뉴를 열면 일시 중지됩니다.

카드 설명

한글, 한 걸음 사용법

한 번에 한 카드, 충분히 읽고 다음으로.

읽기
← / →는 이전·다음 카드, Enter는 뜻과 발음 확인입니다. Space는 글자나 어절을 한 칸씩 비춥니다. ↑는 파트 선택, ↓는 확인입니다. 버튼에 키보드 초점이 있으면 Enter는 그 버튼을 실행합니다.

큰 화면
F는 집중 모드입니다. 전체 화면 버튼은 브라우저에 전체 화면을 요청합니다. 리모컨 키가 웹페이지에 전달되지 않을 때는 화면 버튼, LG 매직 리모컨 포인터 또는 USB/블루투스 키보드를 사용하세요.

CSV 최소 열
part와 korean은 필수입니다. id, part_title, order도 유지하는 것을 권장합니다. 열은 이름으로 읽으므로 중간에 새 열을 넣어도 기존 열 이름이 같으면 작동합니다.

카드 내용
type: letter, combine, word, sentence, particle, pattern, sound, dialogue.
english: 영어 뜻 또는 영어 질문.
pronunciation: 교사가 확인한 한글 발음 표기. 자동 추측하지 않습니다.
rule_ko / rule_en: 한국어·영어 설명.
chunks: 한 칸씩 읽을 단위. 예: 저는|밥을|먹어요.
focus: 강조할 단어나 조사.
steps: 변환 단계. 예: 집 + 에|ㅂ + ㅇ|지베.
tts: 음성에 읽힐 내용. ㄱ 카드에는 기역을 입력.
audio_url: 직접 재생 가능한 HTTPS 오디오 주소.
enabled: FALSE이면 수업에서 제외.
source: 참고 출처.

발음 자료
기본 카드의 발음 표기는 학습 편의를 위해 장단음 표시를 생략했습니다. 복수의 허용 발음은 설명에 표시합니다. 변환 단계의 중간 표기는 설명용이며, 최종 표준 발음이나 철자 변경을 뜻하지 않습니다.

연결이 끊겼을 때
마지막으로 저장한 수업을 계속 사용합니다. 새로고침이 실패하면 동기화 완료로 표시하지 않습니다. 처음 연결할 때는 시트의 웹 게시 권한과 CSV 주소를 확인하세요.

설치 없이 실행
PC에서는 index.html을 열면 기본 수업이 작동합니다. TV에서는 index.html을 올린 HTTPS 웹사이트 주소로 접속하는 방식을 사용하세요. 이 파일 자체가 웹사이트에 자동 배포되지는 않습니다.
